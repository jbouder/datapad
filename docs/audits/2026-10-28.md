# Web App Audit — datapad

**Audited:** 2026-10-28 · **Commit:** `2a28992` on `main` · **Scope:** full (25 dimensions)
**Stack:** React 19 + Vite + Tailwind v4 (shadcn base-lyra), Cloudflare Workers, one SQLite-backed Durable Object per verified email, R2 backups, KV for MCP OAuth, Cloudflare Access in front, bun, Biome, Vitest in workerd, Playwright + axe

## Summary

**Overall maturity: 2.9 / 4** — a carefully built single-user app with
unusually strong security boundaries, data integrity and accessibility.
It is weakest where a production service meets its own operation: release
and rollback, alerting, and frontend performance.

The security boundary is the best part. Access is checked before any
routing, the Durable Object is named only by the verified email, every input
is checked against a zod schema, and each of these has a test. The security
review (#39) closed the gaps it found the day before this audit. No Security
dimension is at 0 or 1, so the score is not capped.

The gaps are operational:
- **Rollback (the one High).** A rollback after a schema bump would run old
  code over a newer layout with no warning.
- **Alerting.** Nothing alerts the owner, and the app does not show which
  version is running.
- **Frontend performance.** The entry bundle is 417 KB gzip, with no route
  splitting and no size budget.

Start with backlog items 1 to 3: refusing a newer schema, closing sockets
when the session ends, and an op allowlist for MCP. Each is a small PR.

### Top risks

1. **Rolling back after a schema bump runs old code over a newer layout** (Release engineering). `ensureTables()` only migrates up, and nothing documents rollback. `worker/datapad.ts:474-475`
2. **Open sockets outlive the Access session** (AuthN/AuthZ). A tab left open keeps full read and write after its session expires or is revoked. `worker/datapad.ts:1296-1310`
3. **MCP's "never deletes" rule rests only on the list of tools.** `apply()` accepts every op, `remove` and `deleteProject` included (AI/agent features). `worker/datapad.ts:866`
4. **No private channel for reporting a vulnerability** on a public repository with an internet-facing OAuth surface (Repo health). No `SECURITY.md`; private reporting is off.
5. **Branch protection is weaker than the docs say** (CI/CD, drift). Only `check` and `e2e` are required, not CodeQL, and no pull request is required. `docs/self-hosting.md:225-230`

## Findings

Ranked most severe first across all dimensions.

### 🔴 High

- **Rolling back after a schema bump runs old code over a newer layout** — Release engineering
  - Evidence: `worker/datapad.ts:474-475`, `if (version >= SCHEMA_VERSION) return;`. A Worker older than the stored schema carries on against tables it does not understand. No doc mentions `wrangler rollback` or versions.
  - Impact: the natural incident response, redeploying the previous version, can hide or corrupt data.
  - Fix: when the stored version is newer than `SCHEMA_VERSION`, refuse every RPC and socket with a clear error, with a test. Add a "Rolling back" section to `docs/self-hosting.md`: `wrangler rollback`, and the rule for rolling back past a schema bump.

### 🟡 Medium

- **Open sockets outlive the Access session** — AuthN/AuthZ
  - Evidence: `worker/datapad.ts:1296-1310` keeps only `{ space }` with a socket. The only close the server makes is when a space is deleted.
  - Impact: a tab left open, on a lost device say, keeps live read and write after the session is revoked in Access.
  - Fix: store the JWT's `exp` (or a maximum age) in the attachment and close with a 4001 code after it. The client reconnects through Access, and its health probe shows "Sign in again". Add a workerd test.
- **MCP's "never deletes" rule is enforced by the list of tools, not by `apply()`** — AI/agent features
  - Evidence: `worker/datapad.ts:866` parses with the full `OpSchema` (`remove`, `deleteProject`, `put`). The only guard is a test of tool names (`test/mcp-tools.test.ts:1022`).
  - Fix: an MCP op allowlist checked in `apply()`, recursing into `batch`, with a test that `deleteProject`, `put` and `remove` are refused.
- **Generic `put` skips the reducer's checks** — Data integrity
  - Evidence: `shared/reducer.ts:307-313` writes the whole document with no reference checks, no activity line and no `updatedAt`. Bulk Undo uses it (`src/components/tasks/BulkBar.tsx:53`, `src/pages/TasksPage.tsx:178`).
  - Impact: Undo overwrites an edit that landed in between, from another tab or MCP, and can point at a project that is gone.
  - Fix: typed inverse ops for Undo (for example `restoreTasks`, which checks references), or run the reference checks inside `put`.
- **No private channel for reporting a vulnerability** — Repo health
  - Evidence: no `SECURITY.md`; `gh api repos/jbouder/datapad/private-vulnerability-reporting` returns `{"enabled":false}`; the only reporting advice is a public issue (`docs/accessibility.md:74`).
  - Fix: a short `SECURITY.md` pointing at GitHub private reporting, with that setting turned on.
- **Branch protection is weaker than documented** — CI/CD (drift)
  - Evidence: required checks are `check` and `e2e`; `required_pull_request_reviews: null`; `enforce_admins: false`. `docs/self-hosting.md:225-230` and `docs/security.md` say CodeQL is required.
  - Fix: add `codeql (javascript-typescript)` and `codeql (actions)` to the required checks and require a pull request (owner setting), or correct both docs.
- **No route-level code splitting; the entry bundle is 417 KB gzip** — Frontend performance
  - Evidence: `src/components/AppShell.tsx:38-51` imports all 14 pages statically; `dist/client/assets/index-*.js` is 1,452,818 bytes (416,758 gzip).
  - Fix: `lazy()` Whiteboard, Help, Digest, Settings, Meeting and Task pages inside the existing page error boundary.
- **No performance guard of any kind** — Frontend performance
  - Evidence: no size budget, analyzer or Lighthouse step in `.github/workflows/ci.yml`.
  - Fix: a budget check on `dist/client/assets` in the `check` job (entry JS and CSS gzip; WebLLM never in the entry chunk).
- **Client errors and 500s cannot be traced** — Observability
  - Evidence: `src/components/ErrorBoundary.tsx:35` only logs to the console; a 500 answers `{error:'Something went wrong'}` with no id (`worker/index.ts:210`).
  - Fix: echo `cf-ray` as `x-request-id` and in the 500 body and log line; a small, size-capped `POST /api/client-error` behind Access that the boundaries call.
- **No alerting, and no visible version** — Observability / Release
  - Evidence: `wrangler.jsonc:47` enables logs only; `vite.config.ts` defines no version.
  - Fix: document a Workers error-rate notification and a backup-failure alert in `docs/self-hosting.md`; build the version and commit into the app and show it in Settings and Help.
- **`Board.tsx` is several concerns in one component** — Structure
  - Evidence: `src/components/board/Board.tsx` (1,627 lines) holds the op builders (`:378-607`), a 400-line pointer-gesture state machine (`:809-1215`), the keyboard map (`:1216-1316`), zoom effects and the render.
  - Fix: a pure `board/gesture.ts` tested like `viewport.ts`, plus `useBoardGestures` and `useBoardKeys`; leave `Board.tsx` as composition and render.

### 🟢 Low

- **PKCE is required only for public clients** — AuthN (drift). The OAuth library skips PKCE for a client that registers as confidential (`@cloudflare/workers-oauth-provider` `validateAuthorizationPkce`); `docs/security.md` says it is always required. Fix: refuse an authorize request without `code_challenge` in `worker/mcp/authorize.ts`, with a test.
- **The MCP rate limit resets on token refresh** — Abuse. It is keyed by the access token (`worker/mcp/server.ts:64-75`) and kept in memory. Fix: key it by grant or client.
- **No HSTS** — Headers. Not in `public/_headers` or `API_HEADERS`; matters on a custom domain. Fix: add it to both and assert it in `test/headers.test.ts`.
- **The summary model's WASM loads from a moving branch without integrity** — Headers. WebLLM's default `modelLibURLPrefix` points at `main` on `raw.githubusercontent.com` (`src/lib/summary-runtime.ts:65`). Fix: an `appConfig` pinned to a commit, with WebLLM's `integrity` option.
- **The Access key fetch has no timeout** — Abuse/resilience. `worker/access.ts:95`; concurrent requests all refetch at expiry. Fix: `AbortSignal.timeout(5000)` and one in-flight promise.
- **The dev bypass depends on configuration alone** — Secrets. `worker/access.ts:156-160`. Fix: honour it only on a localhost hostname, and fail the deploy when `ACCESS_AUD` is empty.
- **No audit trail of security events** — AuthN. Granting, revoking, erase, space deletion and import log nothing. Fix: one JSON line each, no email or token, listed in `docs/architecture.md`.
- **Write scope is pre-ticked when a client asks for no scope** — AuthN. `worker/mcp/consent.ts:123-140`. Fix: tick it only when `write` was requested.
- **Retention has no end and full deletion leaves R2 and KV behind** — Privacy. `docs/data.md:214-295`. Fix: a full-delete checklist (object, R2 prefix, KV grants) and an optional age limit for `before-*` copies.
- **The reducer switch is not exhaustive** — Data integrity. `shared/reducer.ts:298-1110` has no `default`. Fix: `default: { const _x: never = op; … }`.
- **Export files carry no format version** — Architecture. `worker/datapad.ts:982`; `migrate()` sniffs the shape. Fix: write `format`, refuse a newer one.
- **MCP writes are not retry-safe; `edit_task` overwrites details without saying so** — AI/agent. A new op id per call (`worker/mcp/tools/write.ts:63`); `edit_task` is marked non-destructive. Fix: an optional `requestId` as the op id; mark a details edit destructive.
- **No prompt-injection framing** — AI/agent. The MCP instructions (`worker/mcp/server.ts:19-29`) do not say document text is data. Fix: one instructions line and a regression test.
- **Bun is unpinned and differs between CI jobs** — Supply chain. `.github/workflows/ci.yml:29,69`, `deploy.yml:58`; no `packageManager`. Fix: pin one version everywhere and test that they agree.
- **Dependabot alerts and security updates were off** — Supply chain. The owner turned them on the same day.
- **Hashed assets are not cached long-term** — Frontend performance. `public/_headers` has only `/*`. Fix: an `/assets/*` block with `immutable`, asserted in the headers test.
- **Stale "events" in product copy** — UX. `index.html:27,40`, `public/site.webmanifest:5`.
- **WAAPI durations repeat CSS tokens as literals** — Motion. `src/hooks/useFlip.ts:23`, `src/lib/motion.ts:103,130`.
- **Two class-name helpers ship** — Structure. 12 `src/components/ui/*` files import `cn` from the `cn` package; the rest use `@/lib/utils`.
- **No license, unused-dependency or coverage checks; the Playwright image is pinned by tag** — Supply chain / Testing.
- **No check that docs and AGENTS.md paths exist; no `CLAUDE.md` pointer; README has no screenshot; labels and topics used unevenly** — Docs / Agent instructions / Repo health.

## Strengths worth keeping

- **Fail closed by construction.** Identity is checked before any routing (`worker/index.ts:72`), and the OAuth exception is one allowlist function (`isProviderPath`) with its own test.
- **The tenant key comes only from verified identity.** `getByName()` takes Access's email, or a grant's, which only Access-verified code writes; the object re-checks every space id.
- **One write path.** The socket and MCP both run `reduce()` in one transaction and fan out the same way, and every op has a reducer test with its activity text.
- **Tests run on the real platform.** The object, SQLite, alarms and R2 run in workerd against the real `wrangler.jsonc`; e2e runs desktop and phone with axe on every route.
- **Accessibility and motion are enforced, not intended.** Contrast is computed as drawn, focus restoration is tested, and both reduced-motion switches are checked frame by frame.
- **AGENTS.md is accurate.** Forty-odd names checked, one stale count.

## Method and caveats

- Gates run: `biome ci .` pass; `npm run build` (wrangler types, `tsc -b`, Vite) pass; `npm test` 884/884 pass.
- Not run in this audit: the e2e suite (it passed on `main` in CI minutes earlier, 4 shards).
- Experience group: static analysis, the production build's output, and the repo's own axe, reflow, motion and focus specs. The deployed app is behind Access, so nothing was measured in production (no Lighthouse, no field Web Vitals), and the `a11y-audit` run against it needs the owner signed in.
- Not verifiable from the repo: the Access application's cookie settings, the Bypass application's paths, Workers notifications, and the production environment's settings.
- Inventory: `scripts/inventory.sh` at 2026-10-28T13:17Z. The five groups were audited in parallel and their findings re-checked at the cited lines before this report.
